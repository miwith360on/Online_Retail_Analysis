# Online Retail Analysis

## Project Overview
This project analyzes an online retail dataset to uncover customer behavior, product performance, and seasonal trends. Key analyses include:
- Customer segmentation using RFM analysis
- Product return rates
- Seasonal product demand trends
- Revenue analysis by country

## Key Visualizations
- RFM Segmentation Heatmap
- Top Products by Return Rate
- Revenue Trends Over Time

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Google Colab

## Insights and Recommendations
- 20% of customers contributed 70% of revenue.
- High return rates for Product A highlight improvement opportunities.
- Germany shows the highest average transaction value.

## Files Included
- `Online_Retail_Analysis.ipynb`: Jupyter notebook with full analysis.
- `cleaned_online_retail.csv`: Cleaned dataset.
- `visualizations/`: Folder with exported plots.
